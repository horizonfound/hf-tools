## 3. Different underneath, on purpose

A photographer sees none of these.

- **One page server, no second one.** Your pass-through to the Assistant's server, your second server's open access and your `reel-label` command have no part in ours: each is one press on a route the page already used.
- **Where things are saved stays ours:** each shoot's hidden folder and the Assistant's own folder on the computer. The kit archive is one small list; no kit is ever moved.
- **The cards of one shoot show as one backup from our own link** between the cards' backups, never from two names that look alike, as you asked.
- **A shoot with one reel is saved byte for byte as before.** The list of reels is written only when a second reel is started or the first renamed. Your record shape is kept.
- **The first reel's assistant pick stays in the kit's own record,** where every older kit and page reads it; each later reel keeps its own in the reel record.
- **Every save says which reel the page shows,** and is refused when another window has opened a different one, so nothing of one reel can be written into another.
- **Which reel a queue post is, is read from the post's own id,** never from something a page sends. No existing id is renamed: the first reel keeps the shoot's reel post, later reels get its id with "-v2", "-v3".
- **The note for a set of stories is kept beside the layout, not in it,** so a note changes no story, no Undo step and no "Already saved".
- **The silence at the top of a song is measured in plain Python,** with nothing installed (yours asks ffmpeg). The two agree to a hundredth of a second on the test sounds.
- **A replaced recording is told by its size, its time and its first megabyte,** not by file times alone, so a shoot copied to a new drive does not take every sound again.
- **Our own drag carries a selection** (yours loads a drag library from the internet).
- **The page sends a shoot's id, never a path;** names reach a page as text only; every save is checked field by field.
- **Another website cannot press the buttons** that open a folder, the folder picker, a report, a clip or the queue.
- **Our look:** DM Sans, no serif, nothing loaded from the internet for the home base.
