Sample photos for a brand-new Assistant (Nicole's v30, section 6)

This folder ships inside the plugin. Until a photographer's first post kit exists, the home page shows the
photos in here in the hello and the four tiles (Reels, Carousels, Stories, Captions), with the small line
"Sample photos. Yours show up here after your first shoot." Once a first post kit exists they disappear on
their own. They never count in any number, the recap, the hello's facts or the posting queue, and show
nowhere else. With no photos in this folder the grey placeholders stay, as before.

Nicole chooses the photos:
- 8 to 10 photos, JPEG, about 1600 px on the long side, a few MB in all (each file must be under 6 MB).
- Her own photos with permission, or stock whose licence allows shipping the file inside a product.
- A few wide (landscape) ones first: the hello is one wide strip, and it uses the wide ones.
- Plain file names (letters, numbers, spaces, dashes). The files are listed in name order.
- No example shoot is made from them (her walkthrough videos cover that).

Only .jpg, .jpeg, .png and .webp files in this folder itself are used; anything else (this file, a folder,
a hidden file, a link) is ignored. The page asks for a photo by its file name only, and the Assistant serves
only files that are in this folder by that exact name.
